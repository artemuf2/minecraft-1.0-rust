# Horizon-Lite

A minimal **Minecraft 1.0 client in Rust** using **`glow` + `glutin`** (OpenGL 3.3).  
Built for low-end GPUs (target: NVIDIA GTX 550 Ti, 2011).  
Forked from **Horizon 26.3** with the wgpu renderer removed and replaced by a custom OpenGL one.

## Architecture

- `crates/horizon-client/src/main.rs` — winit event loop, menu state machine, input.
- `crates/horizon-client/src/gfx.rs` — OpenGL renderer (terrain atlas, 2D rects, GUI sprites, text).
- `crates/horizon-client/src/assets.rs` — loads `facts.json`, block textures, font (`font/default.png`), GUI atlas.
- `crates/horizon-client/src/mesher.rs` — `mesh_block(pos, top, side, bottom)` and `mesh_blocks`.
- `gen_world_data.py` — generates `facts.json`, `block-models.json`, `block-tags.json` from `textures/`.

The wgpu renderer, streaming, LOD, entities and gameplay modules of Horizon 26.3 are **not used** — they are gated behind a disabled `horizon` feature.

## Running

Requires (in the working directory):

- `facts.json` — block registry (generated by `gen_world_data.py`)
- `textures/` — 508 sprite PNGs
- `gui/` — `button_normal.png`, `button_hover.png`, `hotbar.png`, `gui.png`, …
- `font/default.png` — Minecraft 1.0 ASCII font atlas

```bash
python gen_world_data.py
cargo run -p horizon-client
